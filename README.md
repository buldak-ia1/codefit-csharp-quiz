# 코드핏

`문제.txt`, `문제2.txt`의 C# 시험 예제, `안드로이드 문제.txt`, `시스템소프트웨어 실습 문제.txt`를 바탕으로 만든 모바일 우선 문제 풀이 웹 앱입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열거나, 프로젝트 폴더에서 정적 서버를 실행합니다.

```powershell
python -m http.server 8000
```

그 후 `http://localhost:8000`에 접속합니다.

## 휴대폰에 설치

- Android Chrome: 상단의 `앱 설치` 버튼 또는 브라우저 메뉴의 `앱 설치`를 선택합니다.
- iPhone Safari: 공유 버튼을 누른 뒤 `홈 화면에 추가`를 선택합니다.
- HTTPS 주소에 배포하면 설치 후 전체 화면 앱처럼 실행되며, 한 번 연 뒤에는 오프라인에서도 사용할 수 있습니다.

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 정적 앱을 GitHub Pages에 자동 배포합니다.

## 기능

- 객관식, 주관식, 빈칸, 코딩 총 122문제 유형별 집중 연습
- 데이터베이스, DLL, 델리게이트, 스레드, FileDialog, 폼, 데이터 교환 분야별 신규 코딩 문제 70개
- 기존 C# 문제와 분리된 안드로이드 전용 50문제 모드
- 기존 문제와 분리된 시스템소프트웨어실습 전용 195문제 모드
- 시스템소프트웨어실습 안에서 기존 유형과 분리된 기본_객관식, 기본_주관식, 기본_빈칸, 기본_코딩 70문제
- 시스템소프트웨어실습 확인_객관식 70문제 풀에서 매번 35문제 랜덤 출제
- 과목별로 독립 저장되는 풀이 기록과 정답률
- 모든 유형을 섞은 랜덤 10문제
- 즉시 채점과 해설
- 코딩 문제 핵심 구문 기반 채점
- 오답만 다시 풀기
- 브라우저 로컬 저장소 기반 누적 정답률과 최근 기록
- 휴대폰 화면에 맞춘 반응형 UI
- 홈 화면 설치, 전체 화면 실행, 오프라인 사용을 지원하는 PWA
